# cxp-knowledge-video
把文章或录音做成知识图解视频

Codex 技能，显示名：**cxp-知识图解视频**。

## 功能

- 根据内容合理分章，每章一张独立图解，延续参考视频的纸张手绘风格。
- 输入文章：轻度改写为口播稿并自动配音；输入录音：转写并保留原声。
- 主图保持稳定，不添加动态强调框、亮框或圈选，章节使用短叠化转场。
- 输出无烧录字幕、无软字幕的 MP4，保留图解标题和关键词，为后期字幕留白。
- 默认竖屏 1080×1920、30fps，附带时长、解码、音量和画面检查流程。

## 安装与调用

将本仓库下载或克隆为 `cxp-knowledge-video` 文件夹，放入 Codex 的技能目录（通常为 `~/.codex/skills/`）。确保结构为 `~/.codex/skills/cxp-knowledge-video/SKILL.md`。

```text
使用 $cxp-knowledge-video，把下面的文章或录音制作成知识图解视频。
```

完整规则见 [SKILL.md](SKILL.md)。

## 依赖与配音

需要可用的 Codex 内置图像生成能力、Python 3.10+、Pillow，以及 PATH 中的 FFmpeg/ffprobe。文章配音使用 `edge-tts`，录音转写可选 `faster-whisper` 和本地模型。请在独立 Python 环境中安装依赖。

默认配音为普通话库存音色 `zh-CN-YunyangNeural`，速率初值 `+18%`，验证短样音约每分钟 290 字；不同文章需要重新检查语速。它是原片讲解风格的近似预设，不是声音克隆，也未证明与原音色一致。在线配音会发送口播文本，不上传参考音频。服务可用性需实际检查。

## 验证范围

创建时通过技能格式校验、真实 TTS、20 秒本地录音转写、三章合成测试，以及 9 秒多的 1080p 无字幕样片渲染与代表帧检查。时间断档、重复图像、遗漏音频尾部、旧时间线带入非空强调列表均有输入校验。尚未完成长文章的全流程回归；每次生产仍需检查中文、图解关系、声音和语义同步。

`assets/` 中的原视频截图只供风格参考，其中已有的字幕和平台标识禁止复制到新视频。`reference-clean-steps.png` 是无字幕的生成样图。参考来源见 [reference-provenance.json](assets/reference-provenance.json)。仓库不包含运行环境、模型权重或本机私有路径。
